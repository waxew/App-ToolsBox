# جعبه ابزار 2.0.0

نسخه 2.0.0 بزرگ‌ترین به‌روزرسانی پروژه تا این مرحله است و تعداد ابزارهای اصلی را به **101 ابزار** می‌رساند.

## محاسبات پیشرفته
- سود مرکب.
- تغییر درصد.
- مالیات معکوس.
- تخفیف چندمرحله‌ای.
- حقوق خالص و اضافه‌کاری.
- سن دقیق پیشرفته و روزهای کاری.
- مساحت و حجم اشکال.
- فیثاغورس و معادله درجه‌دو.
- ب.م.م و ک.م.م.

## متن و ابزار توسعه
- تبدیل ارقام فارسی/عربی/انگلیسی.
- مرتب‌سازی و حذف خطوط تکراری.
- Case Converter.
- JSON Formatter.
- URL و HTML Encode/Decode.
- UUID Generator.
- Hash Suite شامل MD5، SHA-1، SHA-256 و SHA-512.
- مقایسه متن، Slug ساز، معکوس متن و شماره‌گذاری خطوط.
- تبدیل اعداد به Roman.

## شبکه
- وضعیت اتصال.
- IP محلی و عمومی.
- DNS Lookup.
- Ping/Reachability.
- Port Test با TCP timeout.
- اطلاعات Wi-Fi.

## تاریخ شمسی
- امروز شمسی.
- تبدیل دوطرفه شمسی/میلادی.
- اختلاف تاریخ شمسی.
- تشخیص روز هفته برای تاریخ شمسی.
- Unix Time.

## شخصی‌سازی و داده
- Theme روشن، تیره و تابع سیستم.
- Grid/List برای صفحه اصلی.
- ذخیره پایدار ابزارهای اخیر و زیرساخت ابزارهای مخفی.
- Backup/Restore نسخه‌دار JSON با Storage Access Framework.
- حفظ علاقه‌مندی‌ها، شمارنده، تاریخچه اسکن و تنظیمات در آپدیت عادی.

## یکپارچگی Android
- Home-screen Widget با نمایش تعداد ابزارها و علاقه‌مندی‌ها.
- Quick Settings Tile برای چراغ‌قوه.
- Back navigation داخلی حفظ شده است.

## حریم خصوصی
- برنامه همچنان Offline-first است.
- ابزار IP عمومی برای نمایش Public IP یک درخواست کوتاه HTTPS به `api.ipify.org` می‌فرستد.
- QR/Barcode روی دستگاه پردازش می‌شوند.
- صدا‌سنج هیچ فایل صوتی ذخیره نمی‌کند.
- Location، Microphone و Camera فقط برای ابزارهای مرتبط استفاده می‌شوند.
- Backup فقط با انتخاب مستقیم کاربر ساخته یا خوانده می‌شود.

## تغییرات فنی
- نسخه: `2.0.0`
- versionCode: `11`
- applicationId: `com.asteam.toolbox` بدون تغییر.
- تعداد ابزارها: `101`
- ماژول‌های مستقل جدید برای محاسبات پیشرفته، متن/توسعه، شبکه، تاریخ شمسی، Backup، Widget و Quick Settings.
- UserPreferences برای Theme، Layout، recent tools، hidden tools و Backup schema توسعه داده شد.

# جعبه ابزار 1.2.0

نسخه 1.2.0 روی ابزارهای اندازه‌گیری حرفه‌ای تمرکز دارد و تعداد ابزارهای اصلی برنامه را از 54 به 61 می‌رساند.

## ابزارهای جدید
- خط‌کش روی نمایشگر با مقیاس میلی‌متر و سانتی‌متر.
- نقاله تعاملی ۰ تا ۱۸۰ درجه.
- زاویه‌سنج زنده Pitch و Roll با شتاب‌سنج.
- لرزش‌سنج نسبی با نمایش شدت لحظه‌ای و بیشینه.
- داشبورد GPS شامل سرعت، مختصات، ارتفاع و دقت.
- مسافت‌سنج GPS برای جمع مسافت حرکت.
- صدا‌سنج نسبی با نمایش dBFS و بیشینه.

## مجوزها و حریم خصوصی
- Location فقط هنگام باز کردن ابزارهای GPS درخواست می‌شود.
- Microphone فقط هنگام باز کردن صدا‌سنج درخواست می‌شود.
- هیچ صدایی ذخیره یا ارسال نمی‌شود؛ پردازش صدا روی دستگاه انجام می‌شود.
- Listenerهای GPS با خروج از صفحه متوقف می‌شوند.
- تمام ابزارهای غیرمرتبط بدون Location و Microphone همچنان کار می‌کنند.

## نکات دقت
- خط‌کش براساس DPI گزارش‌شده توسط دستگاه است و برای اندازه‌گیری صنعتی کالیبره نیست.
- صدا‌سنج `dBFS` نسبی نمایش می‌دهد و جایگزین dB SPL کالیبره نیست.
- دقت GPS و مسافت‌سنج به سخت‌افزار، محیط و کیفیت سیگنال وابسته است.

## تغییرات فنی
- نسخه: `1.2.0`
- versionCode: `3`
- تعداد ابزارها: `61`
- اضافه شدن ماژول مستقل `ProfessionalMeasurementTools.kt`.
- حفظ applicationId و داده‌های محلی نسخه‌های قبل برای نصب Update روی نسخه قبلی.

# جعبه ابزار 1.1.0

نسخه 1.1.0 روی ابزارهای دوربین، QR و اسکن تمرکز دارد و تعداد ابزارهای اصلی برنامه را به 54 می‌رساند.

## قابلیت‌های جدید
- اسکن زنده QR و Barcode با CameraX و ML Kit.
- اسکن از گالری، کنترل فلش، توقف خودکار پس از تشخیص و «اسکن مجدد».
- بازخورد صوتی و ویبره، تشخیص نوع محتوا و اکشن هوشمند.
- تاریخچه محلی تا 100 نتیجه با حذف انتخابی.
- ذره‌بین و آینه.
- QR ساز حرفه‌ای برای متن/لینک، Wi‑Fi، vCard، تلفن، SMS و Email.
- ذخیره و اشتراک PNG با FileProvider.

## حریم خصوصی
- پردازش QR و Barcode روی دستگاه انجام می‌شود.
- فایل QR برای Share فقط از cache محدود برنامه در اختیار برنامه مقصد قرار می‌گیرد.
