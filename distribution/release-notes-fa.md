# جعبه ابزار 2.0.1

نسخه 2.0.1 یک به‌روزرسانی تجربه کاربری و تست سخت‌افزار است و تعداد ابزارهای اصلی را روی **111 ابزار** نگه می‌دارد.

## مرکز تست سخت‌افزار
- بررسی واقعی وضعیت GPS و مجوز Location.
- بررسی وجود میکروفون و مجوز Record Audio.
- نمایش تعداد سنسورهای گزارش‌شده توسط Android.
- بررسی وجود/تعداد دوربین و مجوز Camera.
- اجرای مستقیم QR Scanner و Barcode Scanner.
- درخواست Pin کردن Home Screen Widget در لانچرهای سازگار.
- درخواست افزودن Quick Settings Tile چراغ‌قوه در Android 13+.
- بررسی مجوز اعلان و اجرای مستقیم Reminder.

## صفحه اصلی و کارت ابزارها
- کارت‌های ابزار در هر اندازه انتخابی ارتفاع یکسان دارند.
- عنوان و توضیح با محدودیت خطوط نمایش داده می‌شوند تا Grid به‌هم نریزد.
- نماد هر ابزار در Badge گرافیکی قرار گرفته است.
- کارت‌ها دارای گوشه‌های گرد، Border و Elevation هستند.
- Header رنگی و Search با فرم نرم‌تر به صفحه Home اضافه شده است.
- اکشن‌های کارت فقط «قلب» و «مخفی» هستند و به‌صورت عمودی نمایش داده می‌شوند.
- گزینه Bookmark/Save/«مجموعه من» از UI حذف شده است.

## ابزارهای مخفی
- تنظیمات دیگر فقط عدد ابزارهای مخفی را نشان نمی‌دهد.
- فهرست کامل ابزارهای مخفی با نام، توضیح و نماد نمایش داده می‌شود.
- هر ابزار را می‌توان جداگانه Restore کرد.
- گزینه Restore همه همچنان وجود دارد.

## اطلاعات فنی
- Version: `2.0.1`
- versionCode: `12`
- Main tools: `111`
- applicationId: `com.asteam.toolbox`
- Kotlin `2.3.21`, Compose/Material 3, minSdk 26, targetSdk 36, compileSdk 37.

## نکته تست
مرکز تست، وضعیت واقعی APIهای Android و مجوزها را می‌خواند؛ نتیجه نهایی GPS، میکروفون، سنسورها و دوربین به سخت‌افزار گوشی و تنظیمات کاربر بستگی دارد.

# جعبه ابزار 2.0.0

نسخه 2.0.0 بزرگ‌ترین به‌روزرسانی پروژه تا این مرحله است و تعداد ابزارهای اصلی برنامه را به **111 ابزار** می‌رساند.

## اندازه‌گیری حرفه‌ای
- خط‌کش، نقاله، زاویه‌سنج و لرزش‌سنج.
- داشبورد GPS، مسافت‌سنج و جهت GPS.
- ارتفاع‌سنج قابل کالیبراسیون با فشار سطح دریا.
- صدا‌سنج نسبی dBFS.
- نمودار زنده 60 نمونه نور محیط.

## محاسبات پیشرفته
- سود مرکب، تغییر درصد، مالیات معکوس و تخفیف چندمرحله‌ای.
- حقوق خالص و اضافه‌کاری.
- سن دقیق پیشرفته و روزهای کاری.
- مساحت/حجم، فیثاغورس، معادله درجه‌دو و ب.م.م/ک.م.م.

## متن و توسعه
- تبدیل ارقام فارسی/عربی/انگلیسی.
- Sort و حذف خطوط تکراری.
- Case Converter، JSON Formatter، URL/HTML Codec.
- UUID و Hash Suite شامل MD5، SHA-1، SHA-256 و SHA-512.
- مقایسه متن، Slug، Roman Number، معکوس متن و شماره‌گذاری خطوط.

## شبکه
- وضعیت اتصال، IP محلی و عمومی.
- DNS Lookup، Ping/Reachability و Port Test.
- Wi-Fi Info و WHOIS.
- سرعت لحظه‌ای شبکه و TrafficStats مصرف داده.

## تقویم شمسی و یادآوری
- امروز شمسی و تبدیل دوطرفه شمسی/میلادی.
- اختلاف تاریخ و روز هفته.
- تقویم ماهانه جلالی.
- مناسبت‌های ثابت خورشیدی و بررسی جمعه/تعطیلات ثابت.
- یادآور محلی Android بدون نیاز به اینترنت یا Exact Alarm special access.

## شخصی‌سازی
- Theme: System / Light / Dark.
- Accent: آبی، سبز، نارنجی، بنفش.
- Grid / List.
- مرتب‌سازی پیش‌فرض، نام یا اخیراً استفاده‌شده.
- اندازه کارت فشرده/معمولی/بزرگ.
- Favorites، مجموعه من، ابزارهای اخیر و مخفی‌سازی ابزارها.

## Backup / Restore
- Backup JSON نسخه 2 با سازگاری Import نسخه 1.
- انتقال Theme، Accent، Layout، Sort، Card Size، Favorites، مجموعه من، ابزارهای مخفی/اخیر، شمارنده و تاریخچه اسکن.
- تصویر پروفایل به دلیل وابستگی URI به دستگاه وارد Backup portable نمی‌شود.

## Android integration
- Home-screen Widget.
- Quick Settings Tile چراغ‌قوه.
- اعلان یادآور محلی.
- Back navigation داخلی.

## QR و Scanner
- QR/Barcode زنده با CameraX و ML Kit و اسکن از گالری.
- توقف خودکار، اسکن مجدد، فلش، ویبره/صدا، اکشن هوشمند و تاریخچه 100 نتیجه.
- QR ساز متن/URL، Wi-Fi، vCard، تلفن، SMS و Email با ذخیره و Share PNG.

## حریم خصوصی و دقت
- QR/Barcode روی دستگاه پردازش می‌شود.
- صدا ذخیره نمی‌شود و Sound Meter مقدار dBFS نسبی است.
- Location/Microphone/Camera/Notification فقط برای قابلیت مرتبط استفاده می‌شوند.
- IP عمومی از `api.ipify.org` و WHOIS از IANA TCP/43 استفاده می‌کند.
- مناسبت‌های قمری متغیر بدون داده رسمی همان سال حدس زده نمی‌شوند.
