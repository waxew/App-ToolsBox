# App-ToolsBox | جعبه ابزار همه‌کاره

`App-ToolsBox` یک جعبه‌ابزار فارسی، ماژولار و Offline-first برای Android است. نسخه `2.0.0` کاتالوگ اصلی را به **101 ابزار واقعی** می‌رساند و در کنار ابزارهای پایه، ماژول‌های دوربین، اسکن، GPS، صدا، محاسبات پیشرفته، ابزارهای متن/توسعه، شبکه، تاریخ شمسی، شخصی‌سازی، Backup و قابلیت‌های سیستم Android را یکپارچه می‌کند.

## قانون مستندسازی نسخه‌ها
هر نسخه باید هم‌زمان در `README.md`، `CHANGELOG.md` و `distribution/release-notes-fa.md` مستند شود.

## وضعیت نسخه فعلی
- نسخه: `2.0.0`
- versionCode: `11`
- تعداد ابزارهای اصلی: `101`
- Kotlin: `2.3.21`
- UI: Jetpack Compose + Material 3
- minSdk: `26`
- targetSdk: `36`
- compileSdk: `37`
- JDK: `17`
- AGP: `9.3.1`
- Gradle: `9.5.0`
- applicationId ثابت: `com.asteam.toolbox`
- معماری: Single Activity + Compose + feature-oriented packages
- ذخیره‌سازی تنظیمات: Local SharedPreferences

## خانواده ابزارها

### اندازه‌گیری، سنسور و دوربین
قطب‌نما، تراز، نورسنج، میدان مغناطیسی، فشارسنج، ارتفاع‌سنج، شتاب‌سنج، ژیروسکوپ، چراغ‌قوه، ذره‌بین، آینه، خط‌کش، نقاله، زاویه‌سنج، لرزش‌سنج، داشبورد GPS، مسافت‌سنج GPS و صدا‌سنج نسبی.

### محاسبات
ماشین‌حساب علمی، درصد، تخفیف، مالیات، سود، وام/قسط، BMI، BMR، تقسیم صورتحساب، نسبت، سود مرکب، تغییر درصد، مالیات معکوس، تخفیف چندمرحله‌ای، حقوق خالص، اضافه‌کاری، سن دقیق پیشرفته، روزهای کاری، مساحت، حجم، فیثاغورس، معادله درجه‌دو و ب.م.م/ک.م.م.

### تبدیل واحد
طول، جرم، دما، مساحت، حجم، سرعت، زمان، حجم داده، فشار، انرژی و زاویه.

### زمان و تاریخ
کرنومتر، تایمر، سن، اختلاف تاریخ میلادی، امروز شمسی، تبدیل دوطرفه شمسی/میلادی، اختلاف تاریخ شمسی، روز هفته و Unix Time.

### دیجیتال، متن و توسعه
عدد تصادفی، تاس، شیر یا خط، رمزساز، Base64، SHA-256، آمار متن، تبدیل مبنا، کلیپ‌بورد، شمارنده، QR ساز، QR Scanner، Barcode Scanner، تاریخچه اسکن، تبدیل ارقام، مرتب‌سازی خطوط، حذف خطوط تکراری، Case Converter، JSON Formatter، URL Codec، HTML Codec، UUID، Hash Suite، مقایسه متن، اعداد رومی، Slug ساز، معکوس متن، شماره‌گذاری خطوط و Backup/Restore.

### سیستم و شبکه
باتری، فضای ذخیره‌سازی، مشخصات دستگاه، لیست سنسورها، وضعیت اتصال، IP محلی، IP عمومی، DNS Lookup، Ping، Port Test و اطلاعات Wi-Fi.

## QR و Scanner
- QR/Barcode زنده با CameraX + bundled ML Kit.
- اسکن از گالری.
- توقف خودکار بعد از اولین نتیجه و «اسکن مجدد».
- ویبره و صدای کوتاه پس از تشخیص.
- اکشن هوشمند برای URL، ایمیل، شماره، موقعیت و Wi-Fi.
- تاریخچه محلی تا 100 نتیجه.
- QR Generator برای متن/لینک، Wi-Fi، vCard، تلفن، SMS و Email.
- ذخیره PNG و اشتراک امن با FileProvider.

## شخصی‌سازی
- Light / Dark / System theme.
- Grid / List برای صفحه خانه.
- ذخیره پایدار علاقه‌مندی‌ها، ابزارهای اخیر و زیرساخت ابزارهای مخفی.
- پروفایل محلی با نام و تصویر.

## Backup / Restore
از طریق Storage Access Framework می‌توان JSON نسخه‌دار از تنظیمات، علاقه‌مندی‌ها، شمارنده، تاریخچه اسکن و شخصی‌سازی تهیه و بازیابی کرد. URI تصویر پروفایل به دلیل وابستگی به دستگاه در Backup قابل‌انتقال ذخیره نمی‌شود.

## Android integration
- Home-screen Widget با تعداد ابزارها و علاقه‌مندی‌ها.
- Quick Settings Tile برای چراغ‌قوه.
- Back navigation داخلی قبل از خروج از برنامه.
- مجوزهای حساس فقط هنگام استفاده ابزار مربوط درخواست می‌شوند.

## حریم خصوصی
برنامه همچنان Offline-first است. ابزار IP عمومی تنها قابلیت فعلی است که برای نتیجه خود یک درخواست کوتاه HTTPS به `api.ipify.org` می‌فرستد. ابزارهای QR/Barcode روی دستگاه پردازش می‌شوند و صدا‌سنج هیچ فایل صوتی ذخیره نمی‌کند.

## Update-friendly
- applicationId ثابت است.
- versionCode در هر Release افزایش می‌یابد.
- کلیدهای SharedPreferences نسخه‌های قبل حفظ می‌شوند.
- داده‌ها، پروفایل، علاقه‌مندی‌ها، تاریخچه اسکن و تنظیمات در آپدیت عادی حذف نمی‌شوند.
- کلید Production Signing باید برای تمام نسخه‌های آینده ثابت نگه داشته شود.

## Build
```bash
./gradlew test
./gradlew :app:assembleDebug
./gradlew :app:assembleRelease
```

GitHub Actions همین مراحل را اجرا می‌کند و APKها و Source Snapshot را به‌عنوان Artifact تولید می‌کند.
