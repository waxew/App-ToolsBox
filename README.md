# App-ToolsBox | جعبه ابزار همه‌کاره

یک جعبه‌ابزار فارسی، آفلاین‌محور و ماژولار برای Android که ابزارهای روزمره، سنسورها، محاسبات، تبدیل واحد، زمان، ابزارهای دیجیتال و اطلاعات دستگاه را در یک برنامه جمع می‌کند.

## قانون مستندسازی نسخه‌ها
هر نسخه باید هم‌زمان در `README.md`، `CHANGELOG.md` و `distribution/release-notes-fa.md` مستند شود.

## وضعیت نسخه فعلی
- نسخه: `1.2.0`
- versionCode: `3`
- تعداد ابزارهای اصلی: `61`
- Kotlin: `2.3.21`
- UI: Jetpack Compose + Material 3
- minSdk: `26`
- targetSdk: `36`
- compileSdk: `37`
- JDK: `17`
- AGP: `9.3.1`
- Gradle: `9.5.0`
- applicationId ثابت: `com.asteam.toolbox`
- معماری: Single Activity + Compose + feature-oriented packages
- ذخیره‌سازی تنظیمات: Local SharedPreferences

## جدید در 1.2.0
### اندازه‌گیری حرفه‌ای
- خط‌کش مبتنی بر DPI نمایشگر.
- نقاله تعاملی ۰ تا ۱۸۰ درجه.
- زاویه‌سنج Pitch/Roll زنده.
- لرزش‌سنج نسبی با Peak.
- داشبورد GPS: سرعت، مختصات، ارتفاع و دقت.
- مسافت‌سنج GPS.
- صدا‌سنج نسبی dBFS.

### حریم خصوصی و مجوزها
- `ACCESS_FINE_LOCATION` و `ACCESS_COARSE_LOCATION` فقط هنگام استفاده از ابزارهای GPS درخواست می‌شوند.
- `RECORD_AUDIO` فقط هنگام استفاده از صدا‌سنج درخواست می‌شود.
- هیچ فایل صوتی ذخیره یا ارسال نمی‌شود.
- Listenerهای Location با خروج از صفحه متوقف می‌شوند.
- ابزارهای دیگر برنامه بدون Location و Microphone قابل استفاده هستند.

### محدودیت دقت
- خط‌کش بر پایه DPI گزارش‌شده دستگاه است و جایگزین ابزار کالیبره صنعتی نیست.
- صدا‌سنج dBFS نسبی نمایش می‌دهد، نه dB SPL کالیبره‌شده.
- دقت ابزارهای GPS به سخت‌افزار و کیفیت سیگنال وابسته است.

## سایر ابزارها
- قطب‌نما، تراز، نورسنج، میدان مغناطیسی، فشارسنج، ارتفاع‌سنج تقریبی، شتاب‌سنج، ژیروسکوپ و چراغ‌قوه.
- ماشین‌حساب علمی، درصد، تخفیف، مالیات، سود، وام و قسط، BMI، BMR، تقسیم صورتحساب و نسبت.

- اطلاعات باتری، فضای ذخیره‌سازی، مشخصات دستگاه و فهرست سنسورها.

## Update-friendly
- applicationId ثابت است.
- versionCode در هر Release افزایش می‌یابد.
- کلیدهای SharedPreferences نسخه‌های قبل حفظ می‌شوند.
- داده‌ها، پروفایل، علاقه‌مندی‌ها و تاریخچه اسکن در آپدیت عادی حذف نمی‌شوند.
- کلید Production Signing باید برای تمام نسخه‌های آینده ثابت نگه داشته شود.
