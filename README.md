# App-ToolsBox | جعبه ابزار همه‌کاره

یک جعبه‌ابزار فارسی، آفلاین‌محور و ماژولار برای Android که ابزارهای روزمره، سنسورها، محاسبات، تبدیل واحد، زمان، ابزارهای دیجیتال و اطلاعات دستگاه را در یک برنامه جمع می‌کند.

## قانون مستندسازی نسخه‌ها

از این نسخه به بعد، هر قابلیت، تغییر UI، رفع باگ، تغییر فنی مهم یا ابزار جدید باید هم‌زمان با انتشار نسخه در خود ریپو ثبت شود. برای هر نسخه سه منبع نگه‌داری می‌شود:

1. همین `README.md` برای معرفی نسخه فعلی و خلاصه تاریخچه نسخه‌ها.
2. فایل `CHANGELOG.md` برای ثبت دقیق تمام تغییرات هر نسخه.
3. فایل `distribution/release-notes-fa.md` برای توضیحات قابل استفاده هنگام انتشار نسخه.

هیچ نسخه‌ای نباید بدون به‌روزرسانی این سه بخش نهایی شود.

نسخه 1.1.0 قابلیت‌های نسخه 1.0.0 را حفظ می‌کند و ماژول دوربین و اسکن را توسعه می‌دهد.

- کنترل فلش داخل اسکنر در دستگاه‌های پشتیبانی‌شده.
- تشخیص نوع محتوای اسکن: لینک، ایمیل، شماره تلفن، Wi‑Fi، موقعیت مکانی، اطلاعات تماس، رویداد تقویم، ISBN، محصول و متن.
- اکشن هوشمند برای نتیجه اسکن: باز کردن لینک، شماره‌گیر، ایمیل، نقشه یا تنظیمات Wi‑Fi.

- حذف تکی آیتم‌های تاریخچه و پاک‌سازی کامل تاریخچه.
- کپی نتیجه اسکن و آیتم‌های تاریخچه.
- اجرای اکشن مناسب مستقیماً از تاریخچه.
- ذره‌بین با دوربین عقب و بزرگ‌نمایی سریع 1×، 2× و 4×.
- آینه با دوربین جلویی.
- CameraX برای Camera Preview و ImageAnalysis.
- ML Kit Barcode Scanning با مدل Bundled و پردازش روی دستگاه.
- حذف مجوزهای بلااستفاده Location و Microphone؛ تنها مجوز حساس فعلی CAMERA است.

### اندازه‌گیری و سنسورها
قطب‌نما، تراز، نورسنج، میدان مغناطیسی، فشارسنج، ارتفاع‌سنج تقریبی، شتاب‌سنج، ژیروسکوپ، چراغ‌قوه، ذره‌بین و آینه.

ماشین‌حساب علمی، درصد، تخفیف، مالیات، سود، وام و قسط، BMI، BMR، تقسیم صورتحساب/انعام و ساده‌سازی نسبت.

### تبدیل واحد
طول، جرم، دما، مساحت، حجم، سرعت، زمان، حجم داده، فشار، انرژی و زاویه.

### زمان و تاریخ
کرنومتر، تایمر، محاسبه سن و اختلاف تاریخ.

### ابزارهای دیجیتال
عدد تصادفی، تاس، شیر یا خط، رمزساز، Base64، SHA-256، شمارش متن، تبدیل مبنای عدد، کلیپ‌بورد، شمارنده دائمی، ساخت QR آفلاین، اسکن QR، اسکن Barcode و تاریخچه اسکن.

### اطلاعات سیستم
اطلاعات باتری، فضای ذخیره‌سازی، مشخصات دستگاه و فهرست سنسورها.

### رابط کاربری و تجربه کاربری
- رابط کاملاً فارسی و RTL.
- جستجوی ابزارها.
- فیلتر براساس دسته‌بندی.
- Grid تطبیقی برای ابزارها.
- علاقه‌مندی‌های دائمی.
- منوی همبرگری از سمت راست.
- پروفایل دایره‌ای با انتخاب تصویر محلی.
- امکان ویرایش نام کاربر.
- صفحات تنظیمات، درباره نرم‌افزار و ارتباط با ما.
- رفتار صحیح دکمه Back؛ خروج مستقیم از صفحات داخلی انجام نمی‌شود و کاربر ابتدا به صفحه قبلی برمی‌گردد.

### زیرساخت انتشار و نگه‌داری
- ساختار Update-friendly با applicationId ثابت.
- نگه‌داری تنظیمات، علاقه‌مندی‌ها و تاریخچه محلی در آپدیت عادی برنامه.
- تنظیم Release Signing و خارج نگه‌داشتن کلید خصوصی از Git عمومی.
- Unit Test برای بخش محاسبات علمی.
- GitHub Actions برای تست، ساخت Debug APK، ساخت Release APK و بسته‌بندی سورس.

## خانه و منوی همبرگری

خانه شامل جستجو، فیلتر دسته‌بندی، Grid تطبیقی و علاقه‌مندی‌هاست. Drawer در رابط فارسی از سمت راست باز می‌شود و شامل پروفایل دایره‌ای، انتخاب تصویر محلی، ویرایش نام، خانه، علاقه‌مندی‌ها، تنظیمات، درباره نرم‌افزار و ارتباط با ما است.

صفحه «درباره نرم‌افزار» اطلاعات فنی بسته را به کاربر نمایش نمی‌دهد و فقط توضیح برنامه و نسخه را نشان می‌دهد.

## حریم خصوصی و امضا

برنامه Offline-first است و مجوزهای حساس فقط هنگام استفاده ابزار مربوط درخواست می‌شوند. QR و Barcode روی دستگاه پردازش می‌شوند و Preview آینه/ذره‌بین ذخیره یا ارسال نمی‌شود. کلید خصوصی Production **نباید در GitHub عمومی Commit شود**. فایل‌های راهنما و قالب تنظیمات امضا داخل پروژه هستند؛ نسخه ZIP خصوصی مالک شامل keystore واقعی خواهد بود.

## بیلد

```bash
./gradlew test
./gradlew :app:assembleDebug
./gradlew :app:assembleRelease
```

اگر `keystore.properties` موجود باشد، Release با کلید تعریف‌شده امضا می‌شود.
